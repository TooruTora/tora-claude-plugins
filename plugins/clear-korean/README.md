# clear-korean

Claude Code가 명확하고 자연스러운 한국어로 응답하게 만드는 output style 플러그인입니다. 번역투와 만능 동사를 걷어내고, 문장 성분을 생략하지 않은 완결된 문장으로 답하게 합니다.

`keep-coding-instructions: true`로 설정해서 Claude Code의 기본 코딩 지침은 그대로 유지합니다. 즉 코드를 다루는 방식은 바뀌지 않고, 사용자에게 보여주는 한국어 산문의 문체만 바뀝니다.

## 무엇을 바꾸나

| 구분 | 적용 전 | 적용 후 |
| --- | --- | --- |
| 만능 동사 | 수정을 진행했습니다 | 수정했습니다 |
| 번역투 | 정상 동작하는 것을 확인할 수 있습니다 | 정상 동작합니다 |
| 명사 나열 | 토큰 비용 추론 함수 오류 발생 시 | 토큰 비용을 추론하는 함수에서 오류가 발생하면 |
| 과장 | 완벽하게 해결되었습니다 | 테스트 3개가 모두 통과했습니다 |

## 설치

Claude Code 프롬프트에서 실행합니다.

```
/plugin marketplace add TooruTora/tora-claude-plugins
/plugin install clear-korean@tora-claude-plugins
```

설치한 뒤 `/output-style`을 실행하고 목록에서 `clear-korean`을 선택하면 적용됩니다. 원래 문체로 돌아가려면 같은 명령에서 다른 스타일을 고릅니다.

## 지침 구성

스타일 본문은 `output-styles/clear-korean.md` 한 파일입니다. 다섯 개 절로 나뉩니다.

- **적용 범위** — 사용자에게 보여주는 한국어 산문에만 적용합니다. 코드, 변수명, 코드 주석, 커밋 메시지, 로그 문자열, 인용문은 프로젝트의 기존 관례를 따릅니다.
- **어휘 선택** — 구체적인 동사를 고르고, 영어 문장 구조를 그대로 옮긴 번역투와 긴 명사 나열을 피합니다.
- **피해야 할 표현 목록** — 실제로 거슬렸던 표현을 `[나쁜 예 → 좋은 예]` 형식으로 모아 둔 목록입니다.
- **문장 구성** — 주어와 목적어를 생략하지 않고, 서술어와 종결어미로 문장을 끝냅니다. 엠대시로 문장 관계를 함축하지 않고, 한 문장에 하나의 판단만 담습니다.
- **어조** — 합니다체를 기본으로 쓰고, 검증하지 못한 것을 검증한 것처럼 쓰지 않으며, 불필요한 공치사를 쓰지 않습니다.

## 표현 목록 늘리기

이 스타일은 「피해야 할 표현 목록」을 계속 채워 나가는 것을 전제로 합니다. 쓰다가 거슬리는 표현을 만나면 `output-styles/clear-korean.md`의 해당 절에 한 줄을 추가합니다.

```markdown
- [나쁜 예 → 좋은 예]
```

수정한 내용을 설치된 플러그인에 반영하려면 다음 순서를 따릅니다.

1. 파일을 수정하고 커밋한 뒤 푸시합니다.
2. `/plugin marketplace update tora-claude-plugins`를 실행합니다.
3. Claude Code를 재시작합니다.

설치할 때 플러그인이 로컬 캐시로 복사되기 때문에, 이 세 단계를 거치지 않으면 레포지토리를 고쳐도 반영되지 않습니다.
