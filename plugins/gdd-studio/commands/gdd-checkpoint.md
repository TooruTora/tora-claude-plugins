현재 세션의 진행 상황을 세션 상태 파일에 저장합니다.

**목적:** 이 체크포인트는 컨텍스트 압축·세션 재개 시 SessionStart 훅이 자동으로 읽어 복원합니다. 따라서 **긴 작업 도중이나 세션을 마치기 전**에 실행하면 진행 맥락이 유실되지 않습니다.

**워크플로우:**

1. **현재 상태 파악:**
   - `production/session-state/active.md`가 존재하면 읽어 기존 내용을 확인합니다(누적 갱신 기준).
   - `git status`/`git log`가 아니라 **현재 대화 컨텍스트**를 근거로 진행 상황을 판단합니다: 지금 어떤 문서·시스템을 작업 중인지, 어떤 섹션이 승인·기록됐는지, 어떤 결정이 내려졌는지, 다음에 무엇을 할지, 무엇이 미결인지.

2. **다음 5개 섹션을 채워 `production/session-state/active.md`를 갱신합니다:**
   - **마지막 갱신**: 오늘 날짜/시각
   - **현재 작업**: 지금 작업 중인 문서(경로)와 진행 중인 섹션
   - **완료된 섹션**: 승인되어 파일에 기록된 섹션 목록
   - **핵심 결정사항**: 이번 세션에서 확정된 창작·설계 결정과 그 근거
   - **다음 섹션**: 바로 이어서 할 작업
   - **열린 질문**: 아직 유저 결정이 필요한 미해결 항목

3. **작성 규칙:**
   - 간결한 사실 위주로 적습니다 — 복원 시 빠르게 맥락을 되살리는 것이 목적이며, 장문 서술은 피합니다.
   - 기존 내용을 덮어쓰되, 여전히 유효한 항목(미해결 질문 등)은 보존합니다.
   - 진행이 없어 채울 내용이 없으면 플레이스홀더(`[...]`)를 유지합니다 — 복원 훅이 무시합니다.

4. **저장 대상:**
   - 이 파일은 **내부 세션 상태**이며 사용자 대상 GDD 산출물이 아닙니다. 따라서 HTML 표시본(`design/html/...`)을 생성하지 **않습니다** — Markdown 정본만 갱신합니다.

5. **완료 후:** 저장된 항목을 1-2줄로 요약해 사용자에게 보고합니다.
